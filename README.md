# 🚀 10 HTML & CSS Projects

> A hands-on journey to become better at HTML & CSS by building 10 projects from scratch.

This repository contains **10 HTML & CSS projects** that I'm building to strengthen my frontend fundamentals through consistent practice.

The goal isn't just to complete 10 projects.

The goal is to **write better HTML, write cleaner CSS, understand layouts deeply, and build stronger frontend foundations through repetition and practice.**

---

## 🎯 Why I'm Doing This

I've learned HTML and CSS, but learning concepts and actually being able to build things confidently are two different things.

So, I'm taking a simple approach:

**Learn → Build → Make mistakes → Fix them → Repeat.**

Through these 10 projects, I want to improve my ability to:

- 🧱 Write semantic and well-structured HTML
- 🎨 Write cleaner and more maintainable CSS
- 📐 Understand layouts and positioning better
- 📱 Build responsive interfaces
- 💪 Strengthen my frontend fundamentals
- 🧠 Improve my ability to turn ideas/designs into working interfaces
- 🔄 Become faster and more confident while building from scratch
